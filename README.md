# やすみの しゅくだい メーカー（MieeL）

夏休み・冬休み・春休みの宿題（A4 プリント）を、子どもの実態に合わせて作るツールです（特別支援教育向け）。印刷、PDF 保存、HTML ファイル保存ができます。

## できること
- **ページ**：表紙（写真）／宿題一覧（できたら○・おうちの人サイン）／カレンダー（予定・スタンプ）／毎日の記録（1週間の表・毎日・平日だけ・2〜3日に1回、天気・起きた/ねた時刻・できたこと・ひとこと）／絵日記（写真も）／思い出写真（1・2・4枚）／観察日記／お手伝い表／早ね早起き表／読書記録／なぞり書き／書き初め／年賀状（はがきサイズ・干支）／自由ページ／表彰状
- **子どもの実態に合わせる**（全ページに反映）
  - 名前：印刷／なぞる／自分で書く
  - 日付：印刷（8がつ1にち（げつ））／なぞる／（　）に書く
  - 文を書く所：なぞり／マス（大18・中14・小10mm）／罫線（広い・普通・狭い）／えらんで○（書かずに絵に○）
  - 天気：絵に○／字で書く、見出し：ひらがな／漢字＋ふりがな
  - ワンタッチの目安：「書くのが苦手」「なぞりから」「マスに書ける」「行に書ける」
- **写真**：休み中の写真を入れると、表紙・絵日記・思い出写真に入ります（日付・ひとこと付き）
- **MieeL のアプリのプリントを入れる**：教材ライブラリ（29本）・なかまわけ・じょしの れんしゅう のプリントを、種類・レベル・問題数・回数を選んで宿題に入れられます（同じサイト oyamasnow358.github.io に公開しているときに使えます）
- **子どもごとに保存**（この端末の中）、「この設定で新しく」で別の子を作成、データの保存・読み込み（写真も含む）
